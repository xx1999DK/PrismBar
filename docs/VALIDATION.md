# 验证记录

日期：2026-10-26，北京时间。当前是本地测试版，不能把待验证项视作通过。

## 已验证

- Intel Mac，macOS 15.7.9（24G830），Swift 6.1.2。
- `bash scripts/test.sh`：21 项行为检查通过，包括延迟、菜单打开及鼠标停留时的收回保护、中英文/全半角搜索、收藏筛选、坏偏好恢复及屏幕坐标边界。
- Intel release 构建成功；本地 ad-hoc 签名及 `codesign --verify --deep --strict` 通过。
- 安装到 `/Applications/PrismBar.app` 并启动。
- `--smoke-test`：原生状态项创建、分隔项宽度折叠/展开、十种 SF Symbol 图标可用、780px 设置视图与正常退出均通过。该检查验证本程序的状态和控件，不代表已验证其他应用图标实际隐藏或点击。
- `--render-previews`：三页设置与十种主题的深浅色抽屉共 23 张原生视图导出。已检查外观、概览、设置、浅色抽屉及深色抽屉。初版 ImageRenderer 无法渲染原生控件，已改用 NSHostingView 原生绘制并重新检查。
- 诊断报告 `accessibility=not-granted`。程序不请求屏幕录制，不执行网络请求。
- 最终源码已成功构建 x86_64 与 arm64 两个 ZIP，均通过 ZIP 完整性与 SHA-256 校验；arm64 二进制格式和签名检查通过。每个安装包约 1.7 MB。
- 最终版本重新通过原生 smoke test，十种主题深浅色的完整联系表已逐项目视检查；修正了图标缩放比例并提高深色主题强调色亮度。
